🔄 CFPC Sync — Pull New Cases Daily
⚠️ 이 기능은 cfpcinc.com 페이지에서만 작동합니다
아래 보라색 버튼을 현재 페이지에서 클릭하면 안 됩니다. 반드시 1단계에 따라 북마크 바에 드래그한 뒤, cfpcinc.com 검색 결과 페이지에서 그 북마크를 클릭해야 합니다.
1 처음 1번만: 북마크 바에 추가
  1. Chrome 북마크 바가 안 보이면 Ctrl + Shift + B
  2. 아래 보라색 버튼을 마우스로 잡고 → 북마크 바로 드래그
🔄 TotalMedix CFPC Sync
↑ 클릭이 아니라 드래그&드롭해서 북마크 바에 올려놓으세요
2 매일: CFPC 사이트 열고 검색 실행
  1. 아래 버튼으로 cfpcinc.com 새 탭에서 열기
  2. 로그인 → Date 필터 설정 (예: 어제~오늘) → Search 클릭
  3. 검색 결과 테이블이 화면에 보이는 상태가 되어야 함
🌐 CFPC 사이트 열기 (새 탭)
3 cfpcinc.com 검색 결과 페이지에서 북마크 클릭
  1. cfpcinc.com 결과 페이지가 떠 있는 상태에서
  2. 북마크 바의 "🔄 TotalMedix CFPC Sync" 클릭
  3. "N new PIDs found. Add to TotalMedix?" 확인창 → OK
  4. 완료 알림 뜸: "OK Added: N / Failed: 0"
▶ 대안 방법: 코드 복사 + 콘솔 붙여넣기 (북마크 안 될 때)

cfpcinc.com 검색 결과 페이지에서 F12 → Console 탭 → 붙여넣기 → Enter

⚠️ Chrome이 "Allow paste" 경고를 띄우면, Console에 allow pasting 입력하고 Enter → 그 다음 코드 붙여넣기

💡 자주 발생하는 문제
  • "Open this on cfpcinc.com..." 알림 → 지금 totalmedix 페이지에서 클릭한 것. cfpcinc.com 페이지로 이동 후 클릭
  • "No PIDs on this page" → cfpcinc.com에서 Search 안 누른 것. 검색 결과가 화면에 보여야 함
  • "All already in DB" → 이미 DB에 있는 PID. 새 케이스 없음 (중복 추가 안 됨)
  • 북마크 바 안 보임 → Ctrl+Shift+B
